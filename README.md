# WebOS · 网页操作系统

一个跑在浏览器里的 **Windows 11 风格**操作系统。零依赖、零构建，双击 `index.html` 就能用。

## 两种形态

同一个系统，两套壳。随时切换，不丢数据。

| | 桌面形态（Windows 11 风格） | 手机形态 |
|---|---|---|
| 外壳 | 壁纸 + 桌面图标 + 居中任务栏 + 开始菜单 | 状态栏 + 主屏网格 + Dock + 手势导航条 |
| 多任务 | 可拖动 / 缩放的窗口 | **卡片式多任务**，全屏页 |
| 应用 | 同一套 Apps，一行代码不改 | 同左 |

**切换方式**（三处都行）：
- 右下角悬浮钮 📱 / 🖥️
- 设置 → 系统 · 形态
- 手机形态：下拉通知栏 → 「桌面模式」

选过的形态会记住，刷新后还在。

### 手机形态细节

- **状态栏**：时钟、信号、Wi-Fi、电量
- **主屏**：4 列网格 + 底部 Dock（4 个常用）
- **应用抽屉**：主屏上滑，列出全部 11 个应用
- **通知栏**：状态栏下拉，含深色 / 主题色 / 桌面模式 / 锁屏 四个快捷开关
- **多任务**：点 ▤ 看卡片，可切换、单个关闭、全部关闭
- **导航条**：◁ 返回 · ▁ 主屏 · ▤ 多任务，Esc 键同返回

## 流程（桌面形态）

```
锁屏（点击/按键进入）
   ↓
桌面（壁纸 + 6 个应用图标，装了商店应用会更多）
   ↓
开始菜单（居底居中、可搜索）  ·  任务栏（居中图标 + 托盘时钟）
   ↓
窗口（可拖动 / 缩放 / 最小化 / 最大化 / 关闭 / 层叠聚焦）
```

## 已装应用

| 应用 | 说明 |
|---|---|
| **文件管理器** | 侧边快速访问、双击进目录、双击文件用记事本打开、新建文件夹、状态栏统计 |
| **终端** | 21 条命令，支持 Tab 补全、目录树、文件内容读写 |
| **记事本** | 打开 / 编辑 / 保存（Ctrl+S）/ 另存为，改动写回虚拟文件系统 |
| **计算器** | 四则运算，带括号与退格 |
| **设置** | 深浅主题、6 种强调色、存储统计、重置文件系统 |
| **应用商店** | 6 款可装应用，带分类、搜索、详情页、安装进度与卸载 |
| **设置** 里还能切系统形态（桌面 / 手机） |

## 应用商店

桌面打开「应用商店」，6 款应用随装随用：

| 应用 | 分类 | 说明 |
|---|---|---|
| **扫雷** 💣 | 游戏 | 三档难度，首点保证不踩雷，右键标旗，数字上双击快速展开 |
| **2048** 🎯 | 游戏 | 方向键 / WASD / 滑动，最高分本地保存 |
| **贪吃蛇** 🐍 | 游戏 | 空格暂停，撞墙或咬到自己结束，最高分本地保存 |
| **画板** 🎨 | 工具 | 7 色 + 粗细 + 橡皮，作品存进 `/Pictures` |
| **时钟** ⏱️ | 工具 | 秒表（带计次）、倒计时（6 个预设）、世界时钟（5 时区） |
| **系统信息** 📊 | 系统 | 屏幕、显卡、CPU、内存、时区、存储占用 |

**安装**：商店里点「安装」→ 走一段进度条 → 自动出现在桌面和开始菜单。
**卸载**：详情页点「卸载」，会同时关掉该应用的窗口、移掉桌面图标。

已安装列表存在 `localStorage`（键 `webos.store.installed.v1`），刷新不会丢。

> 说明：这里没有真正的包下载。所有应用的代码都在这几个 JS 文件里，
> 「安装」做的是把应用挂进系统、记住状态——这是纯前端能做到的形态。

## 终端命令

```
help            显示帮助
ls [目录]       列出内容        cd <目录>      切换目录
pwd             当前路径        cat <文件>     查看内容
mkdir <名称>    建文件夹        touch <名称>   建空文件
rm <名称>       删除            mv <源> <目标> 移动
cp <源> <目标>  复制            write <文件> <内容>
find <关键词>   按名搜索        tree           目录树
stat            文件统计        open <路径>    用对应应用打开
theme [d|l]     切换主题        reset          重置文件系统
whoami / date / clear / echo
```

**Tab 补全**：输入前几个字符按 Tab，自动补全当前目录下的文件名。

## 虚拟文件系统

一棵内存里的目录树，持久化到 `localStorage`（键 `webos.fs.v1`）：

```
/
├── Documents/   欢迎.txt · 待办.txt
├── Pictures/    说明.txt
├── System/      version.txt · README.md
└── readme.txt
```

你在终端里创建的文件、记事本里保存的内容，刷新页面都还在。设置页可一键重置。

## 文件结构

```
index.html     锁屏 / 桌面 / 窗口层 / 任务栏
styles.css     Fluent 亚克力、圆角、阴影、动效

storeapps.js   商店里 6 款应用的实现
store.js       商店目录、安装 / 卸载、持久化、商店界面
phone.js       手机形态外壳：状态栏 / 主屏 / Dock / 抽屉 / 多任务 / 通知栏
os.js          形态调度、窗口管理、任务栏、开始菜单、时钟、主题、拖拽
```

## Windows 11 风格细节

- **居中任务栏** + 居中开始按钮，托盘有时钟
- **亚克力毛玻璃**（`backdrop-filter: blur(40px) saturate(180%)`）
- 窗口圆角 12px、Focus 时描一层强调色边
- 最大化按钮、双击标题栏最大化、右下角拖拽把手
- 最小化 / 还原动画、窗口层叠定位（每个新窗偏移 28px）
- 开始菜单：搜索框 + 6 列应用网格 + 用户/锁定区
- 深浅两套完整配色，6 种强调色可换

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也可以（纯静态，无需服务器）。

## 已知边界

- 文件存 `localStorage`，约 5MB 上限，不适合放大量数据
- 无真正的多进程 / 权限模型，只是 UI 层的模拟
- 移动端窗口强制全屏（屏幕太小，不做自由拖拽）
